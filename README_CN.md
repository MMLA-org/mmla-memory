## 证据边界

**已验证证据。** 公共 V3 与 R25 仅保留项目证据台账已经准入的证据。R25 对既有材料进行重组和衔接，不新增实验运行、基准结果或经验性结论。

**已登记负结果。** 空结果、负对照、未决比较和停止规则继续保持负面或未决状态。本交付包不会把“缺少证据”改写为正结果。

**理论后续论文。** 五篇 R02 提供显式假设、类型化模型、证明、反例与可证伪义务；它们不证明 oracle gap、学习得到的准入策略、已合格的语义接口、双状态经验成功或完成段整合的经验成功。

公共叙事前序版本为 [arXiv:2606.28876](https://arxiv.org/abs/2606.28876)。R25 与五篇 R02 的科学验收仍完全由 Reviewer 负责。
